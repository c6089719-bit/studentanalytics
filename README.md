# Student Performance Analytics Dashboard

A web-based Student Performance Analytics Dashboard built using Python, Pandas, Matplotlib, Flask, HTML and CSS.

## 📌 Project Overview

This project analyzes student academic performance and presents meaningful insights through an interactive dashboard.

## 🚀 Features

- Student performance analysis
- Average marks analysis
- Top-performing students
- Subject-wise performance insights
- Performance visualization using charts
- KPI-based dashboard
- Data analysis using Pandas
- Flask-based web application

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Flask
- HTML
- CSS
- MySQL
